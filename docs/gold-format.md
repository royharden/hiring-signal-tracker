# Reference-label boundary

No real or independent synthetic Gold body is supplied by this implementation.
The app's closed annotation schema lives at `src/hiring_signals/annotation/schemas.json`.
It describes safe field decisions, source pins and neutral commands, not a second
canonical S2 rulings/evalkit wire. The actual published rulings adapter maps the
source classes and preserves their licensed closure. The canonical evalkit library
and its public synthetic controls are vendored separately. App-specific pure label
codecs use its actual GoldRecord/FieldLabels classes. The private domain adapter
now joins concrete execution to the canonical runner; private statistics, the full
experiment and quality release remain pending. A journal acknowledgement is not
an eligible Gold export.

Every required field has independent presence: **present** with its actual typed
value (including false, explicit none, multiple and a supported unknown class),
**absent** with typed null for genuinely unstated source, or **unlabelled** with null.
Absence maps to the not_stated scored class; unlabelled stays ineligible. Unknown
mandatory fields/missing field labels reject before an eligible reference export.
Salary ranges keep exact decimals/currency/period; multiple seniority retains its
distinct declared levels. Do not put raw text, names, snippets, links or arbitrary
errors into labels/provenance. Source references remain private opaque handles.

Reference Gold and human-effective predictions are different roles. Supported,
actually human-corrected reference labels can remain valid references; a later
human correction of a machine prediction must not replace that raw machine output
when scoring machine automation. Agent-provisional/staging records cannot establish
human Gold, self-agreement or empirical extraction quality.

The later frozen experiment must use the actual S2 manifest/runner/statistics
interfaces: full IDs/group-constrained splits/source and label hashes, pinned
rubric/taxonomy/config/model/scorer/price/capture versions and heldout history.
Target300 real corrected rows/four months, provisional150/150 split and20 blind
repeats>=7days remain owner prerequisites, not generated receipts. More than5%
stale heldout blocks the real benchmark pending an owner-approved successor;
never silently reseal history. Calibration/default selection is dev-only with
the required support before heldout. Missing human provenance/repeats are unmeasured.

Independent data authors/seals/blinding remain controlled separately. The tuner
does not author a60-post/four-month Gold corpus or generator in this module.
Only small original syntax/controller controls were written. No source body,
private annotation journal, heldout labels or provenance file is copied into
the public product repo.

The pure `evaluation.labels` codec requires all37 explicit field labels and
revalidates nested mutable wire contents. It preserves false, absent and unlabelled
values, exact salary decimal ranges with unknown units and actual multiple levels.
Human references require an injected authority after domain validation; test spies
do not establish actual human trust. Raw-machine projections reject human/reference
records and keep each field's processing/error/certainty metadata. They produce no
Prediction, Outcome, metric or benchmark by themselves.

`evaluation.domain` uses the unchanged canonical comparison runner and its published
axis-status port. Only actual concrete rules, zero-outbound Jev replay or injected
generation execution can issue a source/code/config-bound private prediction in
the current in-process registry. A supplied payload and matching hashes alone do
not issue a prediction. This registry is trusted Python code, not authentication
against hostile callers. Source changes invalidate earlier issuance.

All37 field outcomes retain typed absence, false, unlabelled, multiple levels and
salary units. A validated complete envelope may retain a partial controller result
while its valid fields remain scoreable; original child failures and partial status
remain in private machine metadata. Whole failed, stale, blocked or unavailable
execution cannot promote fields. Actual canonical child counters, capture/request
identities and accounting references remain distinct. Methods receive only the
current source text, not scorer Gold. Missing heldout admission/history rejects
before the frozen reader; supplied objects are not data-read authorization.
No public quality projection is enabled by this domain adapter. These controls do
not establish independent Gold, human agreement or measured model quality.

The separate private metrics adapter composes actual canonical class statistics,
fixed-bin calibration and whole-family paired resampling. It validates complete
expected axes and actual machine issuance, retaining errors, unlabelled cells and
score-coverage denominators. It opens no source/Gold files, supplies no heldout
authorization or human authority, and selects no threshold or production default.

`evaluation.majority.fit_dev_majority` fits a private reference baseline through
the unchanged canonical frozen JSONL reader, selecting only the dev split. It binds
actual manifest/dev-byte/order/source-code hashes, label versions, an explicit
eligible-support minimum and a deterministic tie policy. Unlabelled cells do not
train; unsupported fields get no guessed defaults. This support policy does not
replace the separate per-class calibration/default-selection requirement. The fit
emits no predictions, extraction candidates, calls, quality scores or public report.
Heldout metadata is retained by the manifest; its bodies are never read by this
fitter. Actual independent labels/rights/history and later prediction integration
remain required.
