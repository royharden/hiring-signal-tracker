# Current limits

The supplied-original-synthetic rules CLI and closed public-report commands work
locally. No live acquisition, job-board scraper, real data-rights grant, hosted
runtime or public publication has been executed. A source's original-synthetic
declaration and identity-review flag are caller metadata, not authenticity or
universal de-identification. Source text remains transient in ordinary Python;
this is not process isolation, guaranteed erasure or protection from OS paging.

Rules use a deliberately narrow declared grammar. Semantic code composes all 37
fields/all 69 native questions and a closed generation schema. The Jev runner
currently accepts synthetic-only zero-outbound replay through the real canonical
ledger/controller. Captures and prices remain synthetic. No SDK installation,
provider credential access, actual model call, calibrated confidence, current
price/account capability or empirical extraction-quality result is established.
Generation's counted content-repair execution awaits a verified owner API.

Salary selection is limited to the existing narrow source-bound candidate grammar.
Unknown units stay stated with normalization abstained; unsupported candidate
syntax reduces recall. Whole-source semantic review coordinates are not localized
evidence accuracy. Absence, explicit negatives, conflicts, multiple levels,
uncertainty and processing failures remain different states.

The taxonomy/rubric are not yet owner-ratified. Required independent synthetic
fixtures/Gold, dev/heldout freezing, canonical evalkit integration, support and
calibration checks, paired statistics and actual human agreement remain incomplete.
The real benchmark still requires an authorized source, 300 corrected rows, a
timing pilot and 20 blind repeats at least seven days later. No measured accuracy,
population change, human agreement or live cost is claimed. Missing prerequisites
are not waivers. Demo/evaluation entry points remain explicitly unavailable.

Private HMAC/SQLite state and the canonical annotation journal require trusted
owner-controlled directories outside the checkout. Windows access control must
be established by the owner; POSIX creation modes do not prove Windows ACLs.
Annotation source authority is single-process and reinstalled after restart.
Journal receipts acknowledge durable writes, not current label authority or human
authentication/Gold eligibility. No hostile multi-user filesystem or power-loss
recovery proof is supplied. The current single-record-per-item prediction store
does not provide multi-method run history; the rules CLI refuses other-method state.

Public releases use one disjoint field partition with all siblings suppressed
when required. This does not establish anonymity or solve every cross-field or
repeated-release correlation. No arbitrary overlapping cohort cuts are supported.
One processing failure conservatively marks the whole method partial, which can
also withhold usable fields. SVG/export checks are not browser visual QA.
Artifact verification proves only its bounded local closure, not source validity,
recipient delivery, deployment or independent application acceptance.
