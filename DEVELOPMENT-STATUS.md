## Lessons learned

- Use explicit UTF8 reads/writes on Windows. Default text decoding can corrupt
  valid Unicode controls. Preserve failed evidence and fix the actual cause.
- Wait for verification to reach a terminal exit before committing or mutating its
  candidate. An emitted file count alone is not a completed check.
- Preserve actual canonical schema metadata in expectations. Zero eligible support
  is NA, and explicit false, absence and unlabelled are different values.
- Keep whole-controller partial/failure states alongside field outcomes. A valid
  complete domain envelope does not turn a failed child into success; a whole
  failure cannot promote individual fields.
- Preserve final physical request identity after repair, actual accounting refs
  and unknown liabilities. Capture hashes are not ledger references. Count transport
  retries and content repair under one admitted attempt ceiling.
- Copied conformance tests need their licensed fixture closure and compatible
  collection binding. Diagnose fixture ordering without silently dropping cases or
  changing the verified upstream algorithms.
- Freeze labels/families independently of the tuner. Synthetic DEV functionality,
  unit counts and artifact hashes do not establish human/heldout quality or release
  authority. Keep source/Gold private and never send scorer labels to methods.
- A nested report manifest seals only that report. The outer artifact manifest
  must also exist before calling the combined evaluator output complete; preserve
  interrupted files and use a fresh destination rather than overwriting a retry.
- Runtime fingerprints bind exact on-disk bytes. Git LF and checkout CRLF editions
  can differ at one commit; preserve that distinction and capture actual runtime
  bindings. Report-only verification is not full-evaluator config equivalence,
  and a new hash never reauthorizes consumed inputs or evaluation.
